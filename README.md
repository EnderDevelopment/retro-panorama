# Minecraft Fabric Mod: Vertical Panorama

Vertical Panorama is a client-side Minecraft Fabric mod for Minecraft 1.21.1 that restores the vertically scrolling title screen panorama motion associated with Minecraft 1.12.2 and earlier. It uses Minecraft's built-in panorama textures and rendering pipeline while smoothly moving the panorama's vertical viewing angle as the title screen is displayed.

## Install

1. Install Fabric Loader 0.16.9 or newer for Minecraft Java Edition 1.21.1.
2. Install Java 21 or newer.
3. Download or build `vertical-panorama-1.0.0.jar`.
4. Copy the jar into the Minecraft `mods` folder.
5. Launch the Fabric 1.21.1 profile.

To build the mod from source, run:

```bash
./gradlew build
```

The compiled jar is created in `build/libs`.

## Use

1. Start Minecraft with Fabric and the mod installed.
2. Open the Minecraft title screen.
3. The panorama will scroll vertically while the title screen is open.

The mod is client-only and does not add commands or configuration options.
